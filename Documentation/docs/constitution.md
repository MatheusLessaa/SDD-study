# Project Constitution

## Princípios

- Clareza > velocidade
- Código simples > abstrações complexas
- Testes são obrigatórios
- Nada entra sem aprovação

## Regras obrigatórias

- Toda feature precisa de spec
- Toda task precisa estar em `tasks.md`
- Toda implementação deve ter teste
- Nenhuma alteração sem passar pelo fluxo SDD

## Proibições

- Código sem teste
- Mudanças fora de spec
- Refatoração não planejada
