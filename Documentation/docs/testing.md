# Testing Strategy

## Regra geral

Toda nova funcionalidade deve possuir testes.

## Tipos de teste

- Unitário (obrigatório)
- Integração (quando aplicável)

## Convenções

- Nome: `FeatureNameTests.cs`
- Local: `/tests/...`

## Regra para o agente

Ao implementar uma task:

- Criar ou atualizar testes relacionados
- Garantir cobertura mínima da funcionalidade
